Care Compass
View on GitHub View Live

Care Compass is a web application built with ASP.NET MVC and C#, designed to deliver structured healthcare information through a scalable and maintainable architecture. The application uses RESTful APIs and Entity Framework for efficient data access and management.

The system follows the MVC design pattern, separating concerns between models, views, and controllers. Razor Views are used for server-side rendering, combined with client-side JavaScript for interactivity. UI components were implemented based on Figma designs, ensuring consistency and usability.

Key functionality includes plan and discount logic, enabling dynamic, data-driven user interactions. The application emphasizes clean architecture, reusable components, and responsive design.

Cloud Budget App View on GitHub

Cloud Budget App is a serverless web application designed to help users track and manage their budgets efficiently. The frontend is built with React and hosted on Amazon S3, with CloudFront used as a CDN to improve performance and global content delivery.

The application leverages AWS Lambda and API Gateway to create serverless backend endpoints for handling transactions and budget logs. User authentication is implemented using Amazon Cognito, ensuring secure access and session management.

The architecture follows a serverless model, enabling scalability, high availability, and cost-efficient resource usage. The project demonstrates integration between frontend and cloud services, as well as best practices in deploying and managing modern cloud-native applications.

AWS S3 CloudFront AWS Lambda API Gateway Cognito React REST APIs

Serverless architecture using AWS Lambda and API Gateway
Static frontend hosting with S3 and CloudFront CDN
User authentication with AWS Cognito
Integration with secure budget management APIs
Scalable and highly available cloud deployment

JS Memory Game
View on GitHub View Live

JS Memory Game is a responsive card-matching game built with vanilla HTML5, CSS3, and JavaScript. Featuring a Sherlock Holmes-themed hair salon ('Sherlock Combs'), the game challenges players to match pairs of styling tools and themed icons under different difficulty levels.

The project is built entirely on web standards without frameworks, demonstrating the capability of pure Vanilla JS for state management, DOM rendering, and user flow coordination. Animations and transitions are handled natively through CSS for maximum rendering performance.

HTML5 CSS3 JavaScript (ES6+) Responsive Design DOM Manipulation Git

Key Features

Dynamic grid generation based on selected difficulty (Beginner vs. Advanced)
Custom card flipping animations using CSS 3D transforms
Move tracking, match detection, and win state conditions
Themed interactive UI and audio/visual cues for matches
Fully responsive layout designed for mobile, tablet, and desktop
