# Technical Stack & Portfolio Architecture

This portfolio is built with a focus on clean code, performance, and modern web standards. It serves as both a showcase of my work and a demonstration of my front-end development capabilities.

## 🛠 Tech Stack

- **Core**: HTML5, CSS3, JavaScript (ES6+)
- **Framework/Library**: React (for complex components) / Vanilla JS (for lightweight interactions)
- **Styling**: Tailwind CSS & Sass (SCSS)
- **Build Tool**: Vite
- **Deployment**: GitHub Pages

## 🧪 Testing Philosophy (QA Expertise)

As a QA-focused developer, I believe that quality is not an afterthought but a foundational part of the development lifecycle.

### Automated Testing Suite
I specialize in building robust automation frameworks using:
- **Cypress & Playwright**: For End-to-End (E2E) testing.
- **Jest & Vitest**: For unit and integration testing.
- **Supertest**: For API testing.

### Quality Gates (CI/CD)
I implement automated quality gates in CI/CD pipelines (GitHub Actions, CircleCI) to ensure:
- Linting and formatting consistency.
- Zero-regression deployments.
- Performance benchmarking.

## 📈 Performance & Security
- **Postman/Swagger**: For comprehensive API validation.
- **k6**: For load and stress testing high-traffic endpoints.
- **Lighthouse**: For ensuring accessibility, SEO, and performance best practices.
